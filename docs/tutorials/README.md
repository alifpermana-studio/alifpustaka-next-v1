# Tutorials

Hands-on tutorials to learn Alif Pustaka features step-by-step.

---

## Available Tutorials

### [Your First Blog Post](./your-first-blog-post.md)
**Time:** 15 minutes  
**Level:** Beginner

Learn the complete editorial workflow from creating to publishing a blog post.

**You'll learn:**
- Create and edit posts as an Author
- Submit posts for review
- Review and approve as an Editor
- Publish content to the public blog

**Start here if:** You're new to the blog management system.

---

### [Managing Users and Roles](./managing-users-tutorial.md)
**Time:** 10 minutes  
**Level:** Beginner

Master user administration and role-based access control.

**You'll learn:**
- Create user accounts
- Assign roles based on hierarchy
- Manage user status (active, inactive, banned)
- Use bulk operations
- View audit logs

**Start here if:** You need to manage team members or understand permissions.

---

### [Setting Up OAuth Authentication](./setting-up-oauth.md)
**Time:** 20 minutes  
**Level:** Intermediate

Configure Google and GitHub OAuth for social login.

**You'll learn:**
- Create OAuth applications
- Configure credentials
- Test OAuth flow
- Handle production deployment
- Troubleshoot common issues

**Start here if:** You want to enable social login for your users.

## Tutorial Format

Each tutorial follows this structure:

- **What You'll Learn** - Clear learning objectives
- **Prerequisites** - What you need before starting
- **Step-by-Step Instructions** - Detailed walkthrough
- **What You've Learned** - Summary of skills gained
- **Next Steps** - Where to go next
- **Troubleshooting** - Common issues and solutions
